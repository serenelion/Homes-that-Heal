## 🌟 ICON 1: FIRST PERMACULTURE-BASED HOME DESIGN

### Visual Design:
**Three Interlocking Circles with Golden Center**

```
     Wellness (Top)
         O
        /|\
       / | \
      /  O  \  <- Golden center (integration)
     /  / \  \
    O-------O
Permaculture  Architecture
```

### Concept:
- **Three circles** = Wellness, Permaculture, Architecture (the three disciplines others keep separate)
- **Overlapping areas** = Partial integration (what competitors do)
- **Golden center point** = Complete integration (what we do)
- **Leaf accent above** = Organic foundation, growth from nature

### Why It Works:
- **Venn diagram familiarity** - Everyone understands overlapping sets
- **Center emphasis** - Gold draws eye to the unique integration point
- **Subtle complexity** - Appears simple, reveals depth on inspection
- **Story it tells:** "Three disciplines, one unified system"

### Technical Details:
- **Size:** 56×56px viewBox
- **Circles:** 10px radius, 2.5px stroke
- **Center:** 5px radius solid gold fill
- **Leaf:** Curved strokes, 1.5px weight, 60% opacity

## 💎 ICON 2: LUXURY MEETS ECOLOGY

### Visual Design:
**Diamond Geometry with Organic Curves**

```
    /\
   /  \
  < ◯ >  <- Geometric diamond + organic curves
   \  /
    \/
```

### Concept:
- **Diamond/square** = Precision, luxury craftsmanship, German engineering
- **Organic curved paths** = Natural systems, permaculture principles
- **Both overlaid** = Perfect integration, not compromise
- **Center circle** = Unity point where excellence meets ecology
- **Solid center dot** = Unshakeable core values

### Why It Works:
- **Visual tension** - Straight lines vs. curves creates interesting dynamic
- **Balance** - Neither dominates, both essential
- **Elegance** - Diamond shape evokes luxury, curves evoke nature
- **Story it tells:** "Precision and nature in perfect harmony"

### Technical Details:
- **Diamond:** 24px per side, 2.5px stroke
- **Curves:** Quadratic bezier paths, 2px weight, 70% opacity gold
- **Circles:** 6px outer (stroke), 3px inner (solid)
- **Symmetry:** Perfect bilateral balance

## 🔄 ICON 3: INTEGRATED SYSTEMS THINKING

### Visual Design:
**Starburst Pattern: One Input → Multiple Outputs**

```
    \ | /
     \|/
  ----●---- <- Central element
     /|\
    / | \
```

### Concept:
- **Central golden circle** = Single element (e.g., greywater system)
- **Four inputs** = Resources/needs coming from different systems
- **Eight outputs** = Multiple functions/benefits radiating outward
- **Branching ends** = Cascading effects, exponential value
- **Connection nodes** = Every output becomes someone else's input

### Why It Works:
- **Immediate comprehension** - One becomes many (clear multiplication)
- **Dynamic energy** - Radiating pattern suggests active processes
- **Permaculture core** - Literally visualizes "stacking functions"
- **Story it tells:** "Every element serves multiple functions, creating cascading value"

### Technical Details:
- **Center:** 6px radius, solid gold
- **Primary arms:** Four cardinal directions, 2.5px stroke
- **Secondary branches:** Eight outputs, 2px stroke
- **Nodes:** 1.5px dots at endpoints
- **Spacing:** 12-16px between layers

### Visual Design:
**Modular Grid with Consistent Quality Markers**

- **Strokes:** 2.5px weight

## 🚀 TECHNICAL SPECIFICATIONS

### Canvas:
- **Size:** 56×56px
- **ViewBox:** `0 0 56 56`
- **Format:** Inline SVG
- **Accessibility:** Semantic HTML wrapper

### Strokes:
- **Primary:** 2.5px (structure, main elements)
- **Secondary:** 2px (overlays, connections)
- **Tertiary:** 1.5px (accents, details)
- **Line caps:** Round (softer appearance)

### Fills:
- **Solid:** Gold center points (6px circles)
- **Transparent:** Most paths (stroke-only)
- **Opacity:** 60-70% for overlay elements

### Colors:
```css
--terra-green: #455643;
--terra-gold: #c9a961;
```

### Responsive:
- SVG scales perfectly at any size
- Maintains crispness on retina displays
- No rasterization artifacts

## 🎨 DESIGN ALTERNATIVES CONSIDERED

### Alternative 1: Photographic Icons
**Concept:** Actual photos of projects, systems, craftsmen  
**Rejected because:** Too literal, would date quickly, hard to maintain consistency

### Alternative 2: Minimalist Line Icons
**Concept:** Single-weight line drawings, ultra-minimal  
**Rejected because:** Too generic, lacks brand personality, doesn't communicate complexity

### Alternative 3: Illustration Style
**Concept:** Hand-drawn, organic illustrations  
**Rejected because:** Doesn't match TerraLux's precision + nature balance

### Alternative 4: 3D/Isometric
**Concept:** Three-dimensional renderings  
**Rejected because:** Too technical, reduces across platforms, overcomplicated

### Chosen: Geometric + Organic SVG
**Why:** Perfect balance of precision and nature, scalable, distinctive, tells stories
